# Apri Global App - Complete Package

## 📱 Project Overview

**Apri** is a premium restaurant delivery application designed with world-class standards for user experience, security, and performance. The app delivers an intuitive platform for customers to order food, track deliveries in real-time, earn rewards, and provide detailed feedback.

### Core Features

- ✅ **Real-time Order Tracking** - GPS-based delivery tracking with live updates
- ✅ **Rewards Program** - Tiered loyalty system (Bronze, Silver, Gold, Platinum)
- ✅ **Mandatory 7-Category Rating System** - Comprehensive feedback on app, food, delivery, agent, speed, taste, and service
- ✅ **24/7 Customer Support** - Multi-channel support (live chat, phone, email, FAQ)
- ✅ **Enterprise Security** - PCI DSS Level 1, GDPR compliant, end-to-end encryption
- ✅ **Biometric Authentication** - Face ID and fingerprint support
- ✅ **Multi-Language Support** - Arabic and English interfaces
- ✅ **User Activity Logging** - Complete tracking from login to purchase completion
- ✅ **Admin Dashboard** - Analytics and performance monitoring

## 🚀 Quick Start Guide

### Prerequisites
- Node.js 18+ and pnpm
- Expo CLI
- iOS/Android development environment (optional)

### Mobile App Setup

```bash
# Navigate to mobile app directory
cd apri-mobile-app

# Install dependencies
pnpm install

# Start development server
pnpm dev

# For iOS (macOS only)
pnpm ios

# For Android
pnpm android

# For Web
pnpm web
```

### View Presentation

**Option 1: Web Browser**
```bash
cd apri-powerpoint
# Open any HTML file in your browser
```

**Option 2: PowerPoint**
- Export slides to PPT/PPTX format using the presentation tool
- Open in Microsoft PowerPoint or Google Slides
