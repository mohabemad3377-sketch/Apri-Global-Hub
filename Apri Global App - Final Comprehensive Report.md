## 🚀 Deployment Instructions

### Local Testing

```bash
# Mobile App
cd apri-global-app
pnpm install
pnpm dev

# Website
cd apri-website
python3 -m http.server 8000
# Open http://localhost:8000
```

### Production Deployment

#### Mobile App (Expo EAS)
```bash
cd apri-global-app

# Build for iOS
eas build --platform ios

# Build for Android
eas build --platform android

# Submit to App Store
eas submit --platform ios

# Submit to Google Play
eas submit --platform android
```

#### Website (Vercel)
```bash
cd apri-website

# Install Vercel CLI
npm install -g vercel

# Deploy
vercel

# Production deployment
vercel --prod
```
